# computervision

## Files Explained

In addition to the libraries / tools listed for the various sections, this paper was written in [QuarkDown](https://quarkdown.com/); which is a Markdown style way of converting to LaTeX documents.

GitHub Link: https://github.com/XavierWattermann/computervision

This section goes over the code repo; saying what each file was responsible for.

- `image_classification.py` -> Main model training script for the Image Classification task

- `classification_report.py` -> Reporting script used to run the trained model (from the script above) against the Hubble data to see how well it preforms; uses sklearn.
